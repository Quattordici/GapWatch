# GapWatch rules

Generated by `gapwatch rules --format markdown`. Rule ids are stable: they never change meaning and are never reused.

Severity: **Breaking** breaks correct existing consumers, **Warning** can break some consumers, **Info** is safe or informational.

| Rule | Severity | Name | What it detects |
|---|---|---|---|
| GW001 | Breaking | OperationRemoved | An operation (method + path) that existed in the base contract no longer exists. |
| GW002 | Info | OperationDeprecated | An operation was newly marked deprecated. |
| GW003 | Info | OperationAdded | A new operation was added. |
| GW004 | Warning | OperationIdChanged | The operationId changed. Generated clients (NSwag, Kiota, ...) name their methods after it, so this breaks callers of the generated code. |
| GW010 | Breaking | RequiredParameterAdded | A new required parameter was added; existing callers do not send it. |
| GW011 | Breaking | ParameterBecameRequired | An optional parameter became required; callers that omitted it now fail. |
| GW012 | Warning | ParameterRemoved | A parameter was removed. Callers that still send it may be rejected or silently ignored. |
| GW020 | Breaking | TypeChanged | A type changed incompatibly. Requests: the server stopped accepting a type it accepted. Responses: the server may now return a type consumers do not expect. (integer to number widening is request-safe only.) |
| GW021 | Breaking | FormatChanged | A format changed incompatibly (for example int32 to int64 in a response, or date to date-time in either direction). |
| GW022 | Breaking | NullabilityChanged | Requests: a nullable value became non-nullable. Responses: a non-nullable value became nullable. |
| GW023 | Breaking | EnumValueRemoved | Request enum: an accepted value was removed, or an enum constraint was introduced on a previously free value. |
| GW024 | Warning | EnumValueAdded | Response enum: a new value can be returned (or the enum constraint was dropped). Consumers with exhaustive handling or strict enum deserialization may fail. |
| GW025 | Breaking | RequiredPropertyRemoved | Response: a property that was always present was removed. |
| GW026 | Warning | PropertyRemoved | A property was removed (an optional response property, or any request property). |
| GW027 | Breaking | RequiredPropertyAdded | Request: a new required property was added; existing callers do not send it. |
| GW028 | Breaking | PropertyBecameRequired | Request: an optional property became required. |
| GW029 | Breaking | PropertyBecameOptional | Response: a property that was always present may now be missing. |
| GW030 | Breaking | VariantRemoved | Request: a oneOf/anyOf alternative that was accepted is no longer accepted. |
| GW031 | Warning | VariantAdded | Response: a new oneOf/anyOf alternative can be returned that consumers may not handle. |
| GW040 | Breaking | RequiredRequestBodyAdded | A required request body was added to an operation that had none. |
| GW041 | Breaking | RequestBodyBecameRequired | An optional request body became required. |
| GW042 | Warning | RequestBodyRemoved | The request body was removed. Callers that still send one may be rejected or ignored. |
| GW043 | Breaking | MediaTypeRemoved | A media type that consumers could send or receive is no longer supported. |
| GW044 | Breaking | SuccessResponseRemoved | A success (2xx) response was removed. |
| GW045 | Info | ResponseRemoved | A non-success response was removed from the contract. |
| GW050 | Breaking | SecurityAdded | An operation that allowed anonymous access now requires authentication. |
| GW051 | Warning | SecurityRequirementRemoved | A previously accepted security alternative (scheme or scope set) is no longer accepted. |
| GW052 | Breaking | SecurityRequirementsReplaced | None of the previously accepted security alternatives is accepted any more, so existing callers can no longer authenticate. |
| GW060 | Breaking | ApiVersionRemoved | Every operation of an API version is gone, and the version was not deprecated first. Clients still on it now fail. Replaces GW001, GW023 and GW043 for those operations. |
| GW061 | Warning | DeprecatedApiVersionRemoved | A deprecated API version was removed. This is the planned path, but clients that ignored the deprecation still fail. Replaces GW001, GW023 and GW043 for those operations. |
| GW062 | Info | ApiVersionAdded | A new API version was added; existing clients keep using theirs. Replaces GW003 for its operations. |
| GW063 | Info | ApiVersionDeprecated | Every operation of an API version is now deprecated. Replaces GW002 for those operations. |
